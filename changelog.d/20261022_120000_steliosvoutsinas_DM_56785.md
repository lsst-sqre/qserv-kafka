### Backwards-incompatible changes

- Replace the `parquet_row_group_cells` setting with `parquet_row_group_bytes` (default 128 MiB) to help contain memory usage for very wide rows or large cells (JSON blobs).

### New features

- Add a `parquet_batch_bytes` setting (default 32 MiB) to limit the size of VOParquet batches before they are converted to Arrow.
