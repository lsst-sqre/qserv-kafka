### Other changes

- Fix `bigquery_size` to report the actual size of the BigQuery query result (from the destination table) instead of the bytes scanned to run the query.
- `bigquery_rate` now derives from the same result size, matching how `qserv_size`/`qserv_rate` already worked.
- Add a `bigquery_bytes_processed` metric for the bytes scanned by BigQuery to run a query (the basis for billing).
